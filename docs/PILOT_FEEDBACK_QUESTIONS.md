# Pilot feedback questions / 试用反馈问题

Ask each tester by email, a call or a shared document. Nothing is collected by the app. / 通过邮件、通话或共享文档收集；应用本身不收集任何数据。

1. What question did you try, and what were you hoping to learn? / 您试了什么问题，希望了解什么？
2. Did the plan step (population, exposure, outcome, methods) match what you meant? Where not? / 计划步骤是否符合您的原意？哪里不符？
3. Could you tell how your wording became MIMIC-IV variables (Design tab)? What was unclear? / 能否看出您的表述如何对应到 MIMIC-IV 变量？哪里不清楚？
4. Where did you get stuck, or what failed, and was the explanation enough? / 您在哪里卡住或失败？解释是否足够？
5. Did the results and checks table make sense? Would you trust or reuse the report? What is missing? / 结果与核查表是否易懂？是否会采用该报告？缺什么？
6. How long did a run take relative to your patience, and how would your own process differ? / 运行时间是否可接受？您自己的流程有何不同？
7. One thing to keep, one thing to change. / 一项应保留，一项应改进。
